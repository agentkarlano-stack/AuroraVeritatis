## Principles drawn from the set
1. **Density with hierarchy**: professional users want many signals per screen, but with clear typographic hierarchy (our charcoal/gold system).
2. **Status at a glance**: trend arrows, severity and freshness timestamps on every item (CFR, World Monitor).
3. **Workspaces persist**: saved layouts for dashboards and charts (Koyfin, TradingView).
4. **Mobile is a first-class client** (Trading 212).
5. **Provenance is our edge**: none of the references labels evidence strength as explicitly as AV's Sourced / Estimate / Unverified / Simulated and Mechanism / Correlation / Hypothesis / Scenario labels.
